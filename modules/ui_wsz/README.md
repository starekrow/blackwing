# ui_wsz

The classic face: an interpreter for Winamp `.wsz` skins. A skin is a zip of bitmaps for
a fixed layout, loaded at runtime as data.

**Status:** a skeleton. No code yet; this page says what the module will hold.

## What it will hold

- The `.wsz` reader: the bitmaps, the region and colour files.
- The main, equalizer and playlist windows, wired to the player's events and tables.
- A stock skin of our own, so nothing is redistributed.

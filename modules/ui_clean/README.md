# ui_clean

The clean face: a modern, library-first player for people who do not want a Winamp skin.

**Status:** a skeleton. No code yet; this page says what the module will hold.

## What it will hold

- Library views over virtualized lists, search, the queue, now playing.
- The visualizer and the bit-perfect indicator.
- Parts shared with `ui_compact`.

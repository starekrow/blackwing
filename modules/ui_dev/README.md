# ui_dev

The development face: a plain, dense, complete view of the player. Every table, every
event, the pipeline's stages, the lead and the scan queue. It is built first, and it is
how the rest is developed.

**Status:** a skeleton. No code yet; this page says what the module will hold.

## What it will hold

- Transport, queue and a library browser, over the API and nothing else.
- Inspectors: `hifi.chain`, the lead and recuts, the scan queue, the event stream.
